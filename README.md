# RO-DBT Diary Beta 0.5.7

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.7
- Replaced the topic-based random Self-Enquiry prompt generator with the cue-based **SE Question Finder**.
- Added 16 general “What are you noticing?” RO-DBT cue groupings.
- Question Finder now shows one starter question with an optional single **Go One Step Further** level.
- **Use This Question** deliberately asks whether to set the question as Weekly Focus or save it for the week; it does not silently replace a therapist-assigned focus.
- After the second level, **Not Useful** returns to the starter instead of creating an unlimited chain of deeper questions.
- Audited all 120 prior built-in prompts: 21 retained as starters, 19 retained as edge-oriented questions, 50 rewritten to reduce leading assumptions, and 30 removed from the active finder because they primarily coached action, communication, regulation, or another skill.
- Preserved the exact 0.5.6 prompt registry for historical saved/favorited IDs so existing saved content is not lost.
- Updated the Setup Guide to distinguish Weekly Focus, Question Finder scaffolding, discovered questions, and the separate private RO self-enquiry journal.
- No answer/reflection field was added to the diary-card app.

## Important
- This update is additive and preserves the existing encrypted vault, diary weeks, backups, and locally imported Loving Kindness audio.
- Do not delete/reinstall the Home Screen app for this update.
- Create a current encrypted backup before updating.
- RO-DBT Diary is not monitored and does not alert a therapist or emergency service.
