# RO-DBT Diary Beta 0.5.10

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.10
- Enabled **Major OC Theme** is now visible on Today immediately below the therapy-week/date context. It remains one weekly value and is edited in Week Setup.
- Enabled **Therapy Alliance & Process Ratings** are now visible on Today near the bottom of the daily card, immediately before completion.
- Therapy Alliance & Process remains a once-weekly, pre-session 0–5 entry. Today and Weekly Review edit the same weekly values rather than creating daily copies.
- **Risk / Medication / Substance** remains daily and continues to appear on Today when enabled.
- Preserved the 0.5.9 first-time Initial Setup flow, 0.5.8 scroll-position fix, Question Finder, PDF behavior, backup format, security model, and all existing diary data structures.

## Important
- This update does not erase or replace an existing local diary.
- Create a current encrypted backup before updating an existing installation.
- Do not delete/reinstall the Home Screen app merely to update.
- Optional fields preserve their intended frequency: Major OC Theme and Therapy Alliance/Process are weekly; Risk/Medication/Substance is daily.
- RO-DBT Diary is not monitored and does not alert a therapist or emergency service.
