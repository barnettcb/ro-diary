# RO-DBT Diary Beta 0.5.11

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.11
- **Weekly Review** now shows Therapy Alliance & Process as a compact, read-only review summary instead of repeating the 0–5 data-entry button grid.
- The **Today** screen remains the entry point for the once-weekly pre-therapy Alliance & Process ratings.
- Weekly Review displays each question with its selected rating, or an em dash when not yet entered.
- Preserved the 0.5.10 optional-field visibility changes, 0.5.9 first-time Initial Setup, 0.5.8 scroll-position fix, Question Finder, PDF behavior, backup format, security model, and all existing diary data structures.

## Important
- This update does not erase or replace an existing local diary.
- Create a current encrypted backup before updating an existing installation.
- Do not delete/reinstall the Home Screen app merely to update.
- Optional fields preserve their intended frequency: Major OC Theme and Therapy Alliance/Process are weekly; Risk/Medication/Substance is daily.
- RO-DBT Diary is not monitored and does not alert a therapist or emergency service.
