# RO-DBT Diary Beta 0.5.5

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.5

- Renamed the app to **RO-DBT Diary** in the installed-app metadata and throughout the user interface.
- Disabled double-tap zoom on the passcode/login screen only while preserving normal zoom behavior elsewhere in the app.
- Refreshed the visual design with somewhat richer blues, pale blue-gray surfaces, and more distinct card/header treatment while keeping the interface restrained and readable.
- No diary data structure, encryption, guided-audio storage, backup format, or workflow changes.

## Important
- This update keeps the existing encrypted vault and diary data. Do not delete/reinstall the Home Screen app for this update.
- Create a current encrypted backup before updating.
- Existing locally imported Loving Kindness audio is preserved by this update.
- Removing the imported audio only removes that audio from this device; it does not affect diary data.
- RO-DBT Diary is not monitored and does not alert a therapist or emergency service.
