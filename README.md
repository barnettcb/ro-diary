# RO Diary Beta 0.5.4

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.4

- Added a Home screen after unlock with direct access to Today, Self-Enquiry, Guided Practices, Review, Week Setup, and More.
- Added Home to the bottom navigation while preserving the existing Today workflow.
- Added Guided Practices with one-time local import, playback, replacement, and removal of a personal Loving Kindness audio file.
- Added a Play Guided Meditation button to the Loving Kindness skill reference.
- Guided audio is stored locally in a separate browser storage area and is not included in diary backups, therapist PDFs, or the GitHub release.
- Corrected the Loving Kindness quick-reference wording to match the RO-DBT sequence: generate warmth, extend it to someone you care about, then to a neutral person.
- Updated offline caching/version references for 0.5.4.

## Important
- This update keeps the existing encrypted vault and diary data. Do not delete/reinstall the Home Screen app for this update.
- Create a current encrypted backup before updating.
- After updating, save your personal Loving Kindness audio file to the iPhone Files app, then open Guided Practices and choose Import Loving Kindness Audio.
- Removing the imported audio only removes that audio from this device; it does not affect diary data.
- RO Diary is not monitored and does not alert a therapist or emergency service.
