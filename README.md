# RO-DBT Diary Beta 0.5.6

Private, local-first RO-DBT diary card beta.

## Changes in 0.5.6

- Added the 0–5 target rating key to Weekly Review so numeric target ratings are unambiguous.
- Added the same target rating key to the therapist PDF export.
- Weekly Review now shows all Notes / Events by default, with a dropdown to switch to **Discuss in Therapy Only**.
- Events marked **Discuss in Therapy** remain visibly flagged in the all-events view.
- No diary data structure, encryption, guided-audio storage, backup format, target scoring, or daily-entry workflow changes.

## Important
- This update keeps the existing encrypted vault and diary data. Do not delete/reinstall the Home Screen app for this update.
- Create a current encrypted backup before updating.
- Existing locally imported Loving Kindness audio is preserved by this update.
- RO-DBT Diary is not monitored and does not alert a therapist or emergency service.
